# 🎯 Custom Cursor

A fun and interactive **Custom Cursor** project built with **HTML, CSS, and JavaScript**.  
This project replaces the default browser cursor with a stylish, animated version to enhance user experience.

---

## 📖 Overview
The Custom Cursor project demonstrates:
- How to override the default cursor
- Smooth animations and transitions
- Responsive design for different screen sizes
- A lightweight and extendable codebase

---

## 🛠️ Tech Stack
- **HTML5** – Structure
- **CSS3** – Styling and animations
- **JavaScript (ES6+)** – Logic and interactivity

---

## ✨ Features
- 🖱️ Custom cursor design
- 🎬 Smooth hover animations
- 📱 Responsive across devices
- ⚡ Lightweight and fast performance
- 🧩 Easy to customize and extend
